# 🚀 Coding Web Tools

> ⚡ An **all-in-one developer platform** combining tools, AI, editors, learning, and utilities — fully browser-first with scalable backend support.

---

## 🌐 Overview

**Coding Web Tools** is a powerful multi-module platform designed for:

* 👨‍💻 Developers
* 🎓 Students
* 🤖 AI explorers
* 🛠 Productivity users

It provides **online editors, converters, AI tools, learning modules, and analytics** — all in one place.

---

## ✨ Features

### 👤 Client Modules

* 🖼 **Image Tools** — convert, compress, process images
* 📄 **PDF Tools** — merge, split, analyze PDFs
* 🤖 **AI Tools** — Gemini & custom AI integrations
* 💻 **Programming** — multi-language support
* 🎬 **Media** — YouTube + news integration
* 🔐 **Login System** — user authentication
* ⚡ **Commands (CMDs)** — dev command library
* 🖥 **Terminal** — browser-based execution
* 🎯 **Interview Prep** — Q&A by language
* 🧠 **Quiz System** — test your knowledge
* 📝 **Notes Tools** — converters + AI text tools
* 📊 **Analytics Dashboard**

---

### 🛠 Admin Panel

* Manage users
* Control tools & modules
* Monitor analytics
* Content moderation

---

### ⚙️ Server (Backend)

* API handling
* File processing
* Authentication
* Real-time communication

## 🔧 Tech Stack

### 🧩 Core Tools

* 📦 **Multer** → File & image uploads
* 🍃 **MongoDB** → Database
* 📧 **Nodemailer** → Email services
* 🔌 **WebSocket** → Live communication
